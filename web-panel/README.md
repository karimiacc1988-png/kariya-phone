# کاریا تلفن — رابط کاربری مرکز تلفن

رابط فارسی و راست‌چین برای مرکز تلفن **Issabel 5 / Asterisk 18** که روی ماشین مجازی
`Voip-Srv` (Rocky Linux 8.8، روی ESXi) کار می‌کند.

خود ایزابل **دست‌نخورده** می‌ماند: هیچ فایلی از کد یا کانفیگ آن ویرایش نمی‌شود.
این برنامه یک اپ جداگانه است که از بیرون با ایزابل حرف می‌زند.

---

## وضعیت فعلی

| بخش | وضعیت |
| --- | --- |
| رابط کاربری کامل (۵ بخش) | ✅ ساخته و اجرا شده |
| داده‌ی نمونه برای پیش‌نمایش | ✅ `public/assets/js/mock.js` |
| اتصال واقعی به مرکز تلفن | 🔴 در انتظار دسترسی SSH به سرور |

تا وقتی سرور وصل نشده، برنامه در **حالت نمایشی** بالا می‌آید و پایین صفحه با برچسب
نارنجی اعلام می‌کند که به مرکز تلفن وصل نیست. هیچ کدی از ماژول‌ها برای اتصال واقعی
تغییر نمی‌کند — فقط `MOCK` در `core.js` خاموش می‌شود و فایل‌های `api/*.php` جواب می‌دهند.

## اجرا برای دیدن

```bash
py -3 -m http.server 8777 --directory C:/ai/kariya-voip/public
```

بعد `http://localhost:8777` را باز کنید.

## ساختار

```
public/
  index.html
  assets/
    css/app.css        ← تمام سبک‌ها؛ رنگ‌ها از UI-STANDARDS-FA.txt
    js/
      app.js           ← پوسته، منو و مسیریاب
      core.js          ← ساخت DOM، لایه‌ی API، قالب‌بندی، مودال، پیام
      table.js         ← جدول استاندارد (مرتب‌سازی، جستجوی ستونی، انتخاب، Ctrl+C)
      icons.js         ← Material Symbols Rounded، گرفته‌شده از مخزن رسمی گوگل
      mock.js          ← داده‌ی نمونه، دقیقاً با شکل خروجی API واقعی
  modules/
    desk/              ← میز کار تماس (تلفن نرم‌افزاری + تماس‌های زنده)
    calls/             ← گزارش تماس‌ها از CDR
    extensions/        ← داخلی‌ها
    trunks/            ← ترانک‌ها و ظرفیت کانال
    settings/          ← تنظیمات AMI، click-to-call و ضبط
```

هر بخش یک پوشه دارد و یک تابع `render(ctx)` صادر می‌کند که یک المان برمی‌گرداند.
اگر المان متد `cleanup` داشته باشد، هنگام رفتن به بخش دیگر صدا زده می‌شود (بستن تایمرها).

## قرارداد API

همه‌ی ماژول‌ها فقط از تابع `api(path, params, options)` استفاده می‌کنند. مسیر واقعی
`api/<path>.php` است و همه خروجی JSON می‌دهند.

| مسیر | روش | خروجی |
| --- | --- | --- |
| `status` | GET | وضعیت مرکز تلفن، کاربر جاری، مصرف کانال |
| `live` | GET | `{rows:[{id,dir,peer,name,ext,state,since,trunk,recording}]}` |
| `cdr` | GET | `{rows:[…],total}` با فیلتر `from,to,dir,dispo,ext,term` |
| `extensions` | GET | فهرست داخلی‌ها |
| `trunks` | GET | فهرست ترانک‌ها |
| `originate` | POST | `{ext, number}` — برقراری تماس |
| `answer` / `hold` / `hangup` | POST | `{id}` |
| `saveExtension` | POST | ذخیره‌ی داخلی |
| `settings` | GET | تنظیمات برنامه |

`state` یکی از `ringing` / `talking` / `hold` است و `dispo` یکی از
`ANSWERED` / `NO ANSWER` / `BUSY` / `FAILED`.

## چیزی که برای اتصال واقعی لازم است

۱. **دسترسی SSH به سرور ایزابل.** آدرس `192.168.66.2` (ESXi) داخلی است و از بیرون
   باز نمی‌شود؛ یا فوروارد پورت روی روتر لازم است یا تونل معکوس.

۲. **کاربر AMI محدود** در `/etc/asterisk/manager_custom.conf`:

   ```ini
   [kariya]
   secret = <رمز قوی>
   deny   = 0.0.0.0/0.0.0.0
   permit = 127.0.0.1/255.255.255.255
   read   = call,cdr
   write  = originate
   ```

   عمداً فقط `originate` — اگر برنامه نفوذ شد، مرکز تلفن قابل بازپیکربندی نباشد.

۳. **دسترسی خواندن به `asteriskcdrdb`** برای گزارش تماس‌ها.

۴. **داخلی `700`** به‌عنوان لایه‌ی واسط پشتیبان، با `Follow-Me` و `Confirm Calls` روشن.

## قواعدی که در این کد رعایت شده

- راست‌چین کامل، تاریخ شمسی، اعداد با ارقام لاتین و `tabular-nums`.
- جدول: ردیف ۳۴px، متن ۱۱px، سرستون سرمه‌ای، ردیف یکی‌درمیان، سلول تک‌خطی،
  جستجوی زیر هر سرستون، جمع/میانگین/تعداد در پانویس، `Ctrl+C` برای اکسل.
- نوار ابزار همه‌ی بخش‌ها یک طرح و یک ترتیب دارد؛ داشبورد و عنوان بزرگ بالای فهرست نیست.
- باز کردن رکورد با **سه‌کلیک، نگه‌داشتن، راست‌کلیک یا Alt+E**؛ دبل‌کلیک فقط انتخاب می‌کند.
- هیچ تب مرورگری خودکار باز نمی‌شود.
- آیکون‌ها از Material Symbols Rounded گوگل گرفته شده‌اند، دستی کشیده نشده‌اند.
