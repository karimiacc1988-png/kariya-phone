# نسخه‌های ساخته‌شده‌ی اپ کاریا تلفن

فایل‌های APK اینجا با **Git LFS** نگه داشته می‌شوند (حجیم‌اند). برای گرفتنشان
`git lfs pull` لازم است، وگرنه فقط اشاره‌گرِ متنی‌شان clone می‌شود.

| فایل | چیست |
|---|---|
| `kariya-phone-v1.apk` | اولین نسخه‌ی نهاییِ امضاشده (۵۷MB، فقط arm64) |
| `kariya-phone-v2.apk` | نسخه‌ی دوم |
| `kariya-phone-v3.apk` | نسخه‌ی سوم — **جدیدترین نسخه‌ی امضاشده** |
| `kariya-phone-v3-debug.apk` | نسخه‌ی دیباگ (۱۲۸MB، بدون امضای release، برای عیب‌یابی) |

🔴 **کلید امضا (`kariya-release.jks`) در گیت نیست.** بدون آن، به‌روزرسانی روی
نصب‌های موجود نمی‌نشیند. نسخه‌ی امنش را جدا نگه دار؛ در GitHub Actions هم به‌شکل
Secret هست. رمزش با کلید نگه داشته می‌شود.

⚠️ **این فایل‌ها خروجی ساخت‌اند، نه سورس.** نسخه‌ی رسمی هر بار با GitHub Actions
از روی سورس ساخته می‌شود (`.github/workflows/`). این‌ها فقط برای در دسترس بودنِ
سریعِ نصبی‌های قبلی این‌جا هستند.
